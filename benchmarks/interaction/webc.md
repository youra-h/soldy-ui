Что видно:

- **Соседей действие не трогает.** Записей в DOM других копий у действий на одной копии нет.
  Записи вне страницы при открытии DatePicker и Dialog (54 и 108 против 5 и 10) — `aria-hidden`
  (у Dialog — на окне и его подложке) на закрытых панелях 49 соседей: открытый слой прячет всё вне себя. По
  атрибуту-двум на соседа — терпимо.
- **Отклик.** Действие на одной копии — до 37 мс до кадра при ×6.
- **Язык страницы.** 50 полей DatePicker — 81–91 мс при ×6, лучший результат из шести; 50 видимых
  календарей — 1,1 с. Записей в DOM на смене языка календарей в 25 раз больше, чем у Vue (25 тыс.
  против 1 тыс.), но это не лишняя работа: сетка собирается заново у всех платформ, а Vue и React
  ставят атрибуты новой ячейке до вставки, и наблюдатель видит одну запись на неделю, а элемент
  Web Components получает их после подключения — по записи на атрибут.

## 2026-10-28 — Web Components, неделя Calendar по месту в сетке

Ключ строки недели — её место в сетке, а не первая дата (задача 869fmu6nz). Смена языка с другим
первым днём недели (`ruRU` ⇄ `enUS`) оставляет в строке шесть дней из семи, и сетка месяца не
пересобирается целиком. Время до кадра на странице `calendar` из 50, мс; «до» — прошлый замер
журнала, «после» — `npm run interaction -- --pages calendar --rates 1,6` (×4 — тем же прогоном):

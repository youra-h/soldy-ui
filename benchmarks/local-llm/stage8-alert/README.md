# Alert: Qwen без Эксперта

**Незавершённый исследовательский кандидат. Не сливать как реализацию Alert.**

Сохранён точный код модели после двух попыток на одном и том же учебном случае Alert. Изменялся только Alert.tsx. Остальные три исходных файла одинаково предоставлены обоим режимам; их подготовка выполнена ранее и не объявляется бесплатной. Код организатором не исправлялся. Эта папка — архив для review, а не самостоятельный установленный пакет. Импорт @pilot/common разрешается только внутри исходного экспериментального harness.

Модель: Qwen3.5-9B Q4_K_M, 32K, reasoning off, seed 42. База: 091781987e9eb0c9d01e35f1e1ff552974827196. Лимит: два патча. Новых целевых облачных вызовов нет; инженерный расход чата неизвестен. Облачная экономия не измерена.

Контроль получает то же публичное API, обязательные правила и доступ к тем же разрешённым исходникам. Индексированного контекстного пакета и инструментов Эксперта у него нет. Кандидат остался с ошибками типов.

React/types и SSR-проверки не прошли. Положительный скрытый контроль прошёл те же проверки; отрицательный контроль упал. Конкретные исходы обеих попыток — в result.json. Прошедшие проверки самого Эксперта не означают правильность кода модели. Один development-case и один seed не являются общим рейтингом моделей.

Raw formatting сохранён вместе с результатом модели. Не запускайте этот архив как production-компонент.

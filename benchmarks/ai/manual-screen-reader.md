# Ручная проверка объявлений

Статус на 2026-11-09: **not-run**. Дерево accessibility и axe не заменяют слышимые объявления.
Прогон проводят одинаково на untouched AI и Soxa после заполнения входной матрицы.
Preflight этой Windows машины: NVDA не найден в PATH, среди процессов и по стандартным
путям Program Files/Program Files (x86). Это не исчерпывающая проверка portable установок;
настроенной связки для реального прогона не подтверждено.

| Окружение                     | Что записать перед началом                                                       |
| ----------------------------- | -------------------------------------------------------------------------------- |
| NVDA + Chromium, Windows      | Версии NVDA/браузера/ОС, язык речи, режим browse/focus, URL/run-id и source hash |
| VoiceOver + Safari, macOS/iOS | Версии VoiceOver/ОС/Safari, язык, Quick Nav, URL/run-id и source hash            |

Для каждого действия записать фактически услышанную фразу, ожидаемый смысл, результат
passed/failed/not-run и причину. Не восстанавливать фразу по DOM. При записи аудио исключить
личные данные; тестовые строки/записи — те же фикстуры протокола.

1. Select: войти Tab, услышать имя/роль/expanded, открыть, пройти стрелками, Home/End,
   поиск и выбор двух опций, удаление выбранного и Escape. Проверить объявление активного
   варианта и сохранение multiple selection, отдельно ru/en/ar.
2. DatePicker: имя поля и части даты, открытие календаря, текущий/выбранный день, смена
   месяца, выбор даты и возврат фокуса. Проверить смысл даты в RTL, без перевёрнутого порядка частей.
3. Dialog: объявление диалога и имени, начальный фокус, обход полей и кнопок в обе стороны,
   недоступность фона в modal, закрытие Escape и возврат к инициатору.
4. Tabs: имя/selected/позиция таба, стрелки/Home/End, связь и объявление содержимого активной панели.
5. Table: имя/заголовки/значения ячеек, изменение aria-sort, выбранная строка/select-all,
   навигация после прокрутки большой коллекции без потери контекста.

Отсутствие возможности проверить конкретную связку остаётся `not-run`, а не passed.
Итог хранить рядом с соответствующим run в JSON с версиями, examiner/date и каждым действием.
